# Nipa Thaimassage & Kosmetik

Production-ready bilingual website for Nipa Thaimassage & Kosmetik in Mannheim.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static production output is generated in `dist/` and can be deployed directly to Cloudflare Workers & Pages.

## Content updates

- Business details: `src/data/business.ts`
- Treatments and prices: `src/data/services.ts`
- German copy: `src/i18n/de.ts`
- English copy: `src/i18n/en.ts`
- Images: `public/images/`
